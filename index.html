RankedBW Plugin

How to Use

  1. Download the RankedBW plugin file.
  2. Upload the file into your server's plugins folder.
  3. Restart your server to generate the necessary files.
  4. Navigate to the newly created plugins/RankedBW/ folder.
  5. Open the config.yml file.
  6. Find the Token field and paste your Discord bot token there to link your bot.
  7. Customize your settings! You can configure Discord channels and other preferences directly in the config.yml.
  8. Make sure to also check and update your permission.yml to grant the correct access to your players.

Server Requirements

  • Server Software: Paper or Spigot
  • Minecraft Version: 1.8.8
  • Java Version: Support for Java 11 and Java 17
