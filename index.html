How to Setup & Use

Quick installation and setup guide for server owners

Paper / Spigot 1.8.8 Java 11 & Java 17 Supported
1
Download the Plugin

Download the rankedbw-bot-1.0.jar plugin file directly from our website.

2
Upload & Restart

Upload the JAR file into your Minecraft server's /plugins/ directory and restart your server.

3
Locate Plugin Folder

After server restart, open the newly generated /plugins/RankedBW/ folder.

4
Set Discord Token

Open config.yml, locate the Token: field, and paste your Discord bot token.

5
Configure Channels & Options

Customize Discord channels, game modes, and settings inside config.yml.

6
Permissions & Finish

Adjust rights in permission.yml, save changes, and reload/restart the server to launch!
